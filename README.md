# Diploma in Law Learning Hub — Option C

A responsive front-end prototype built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet is only needed for the optional Google Fonts import; the rest of the demo is local.

## Included
- Responsive homepage and navigation
- 30 editable sample module cards and module detail dialogs
- Search and category filters
- Case-law, legislation and legal dictionary tabs
- Five-question interactive quiz with explanations
- Flashcards
- Study planner with local browser storage
- Progress indicators saved in local storage
- UNISA exam-practice link: https://adovh.unisa.ac.za/my/courses.php
- Privacy Policy and Terms of Use starter content
- Demo registration/sign-in modal

## Important before public launch
This is a front-end demo, not a production-ready student account system. Registration and sign-in are intentionally simulated and do not create accounts or transmit data. Do not collect real passwords using this prototype.

For real student accounts across devices, connect a secure authentication provider and database. Enforce row-level permissions so students can access only their own records, protect administrator routes, and configure secure backups and recovery.

The 30 module names are illustrative placeholders, not a verified official UNISA Diploma in Law curriculum. Replace them with the actual curriculum and verified module codes before publishing. Review case citations, legislation and all learning content against authoritative sources.

Replace privacy and contact placeholders and review the Privacy Policy against actual data practices and applicable South African law, including POPIA where applicable. The site is independent and is not affiliated with UNISA.
